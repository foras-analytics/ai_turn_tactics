# Project context

## Goal

Build a small turn-based game engine and have LLM players compete against each other through it.

## Current state

The project has contributor instructions and a README. The engine, game rules, and LLM player integration are still to be implemented.

## Open decisions

- Game rules, turn structure, legal moves, and win conditions.
- Implementation language and engine interface.
- What each LLM player can see, how it submits a move, and how the engine handles invalid responses.
- How matches will be configured, run, and reported.
