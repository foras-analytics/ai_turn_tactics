# AI Turn Tactics

AI Turn Tactics is a project to build a small turn-based game engine where LLM players compete against each other.

## Getting started

The engine is still to be implemented, so there are no installation or run commands yet. As the implementation lands, this section will cover prerequisites, dependency installation, LLM configuration, and how to run a match and the test suite.

For the current project state and open decisions, see [project_context.md](project_context.md). Contributor instructions are in [AGENTS.md](AGENTS.md).
